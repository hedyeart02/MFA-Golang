🏢 Schneider Electric EcoStruxure IT Advisor (ITA) Setup Guide

  1. Log in to ITA Web Client (https://192.168.0.119) as an administrator.
  2. Navigate to Administration > External Authentication > SAML 2.0.
  3. Set IdP Entity ID: {{.Settings.EntityID}}
  4. Set Single Sign-On Service URL: {{.Settings.SSOURL}}
  5. Set Single Logout Service URL: {{.Settings.SLOURL}}
  6. Download the SAMLGuard Signing Certificate from the Certificates & Metadata tab and upload it to ITA.
  7. Important (Option B Behavior): Users must be created or invited inside ITA. SAMLGuard forwards the verified user's NameID/Email. If the user does not exist in ITA, ITA will reject login.

🕒 Time Synchronization & Clock Skew Diagnostics

SAML 2.0 assertions enforce strict timestamps via NotBefore and NotOnOrAfter conditions. Virtual Machines (such as Rocky Linux ITA VM on Hyper-V) frequently experience 1–3 minute clock drifts against the Windows host. SAMLGuard automatically incorporates a 5-minute buffer in the past (now - 5m) to completely eliminate "Assertion cannot be used before" errors (Error code 114004).
